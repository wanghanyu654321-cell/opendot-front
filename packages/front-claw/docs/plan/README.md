# 迁移计划

## 1. 总体顺序

1. **离线开发**（进行中）：M01–M08 八个里程碑，加修复轮 R1–R23，直到离线门禁（门① ≥ 95%、门② = 0）由独立复审准入。
2. **接入企微**：重新连接智能机器人长连接。需要 hanyu 提供并批准企微 ID（D109）。
3. **腾讯云迁移**：现有服务全部下线、从头部署（hanyu 11-12 20:11 定）。下线前先确认旧库里有没有要导出的业务数据（预约、员工、门店、企微 ID 映射）。
4. **正式真实测试**：接真模型、真企微，在 B 店用测试账号逐级降权；判门③、门④，复核门①、门②；做 21 项验收。
5. **OpenDot 隔离迁移与切换**：用 M08 工具迁移数据，演练回退（保留迁移后新增数据）。

第 2–5 步每一步都需要 hanyu 本人批准，见 [approvals.md](approvals.md)。

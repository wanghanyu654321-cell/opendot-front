# R15 议题（对照 D144 与转向）

产品负责人已定 D144：快通道只算纯标准行；「否定补报＋标准行」和复合进度（D141）都归模型路径，离线桩先追问可接受。没见过的说法一律先问，不进备注、不进客户名。第 2 档「带时间词的否定补报前缀、逗号、已知客户全名、冒号、金额」不用改成快通道；桩追问可更具体（是不是要报这位客户的单），但不能出可确认草稿。新 D 号从 D145 起。R15 目标：门②保持 0；纯标准行不退化；没见过的说法一律先问。D143 / D131 / 评测回放不动。

## 要办的

1. 复合本人进度：用结构判断（自我指示＋业绩义素＋问句/请求语气），不用短语表。进度不进备注、不进客户名。已能结构认出的，仍落实 D141：报单出草稿、真的查本人进度（r3/r11/r14 既有口径）。问别人的进度走原隐私规则。「算下这周还差几单」维持「（评测原句已删）」，不扩成查询。
2. 否定补报：D142 配置里固定说法仍先剥，剥完走 D139/D131（可出草稿）。结构像「否定＋补报」但不是配置里的：一律先问，不进客户名和备注，不出可确认草稿。能看出客户和金额时，追问写成「是不是要报客户「X」这一笔」。项目白名单（补水等）优先，不误伤「不用补水」。
3. 剥完/拆完后无法识别的碎片：先问，不进备注、不进客户名，不出可确认草稿。
4. 「是新客户 X 吗」非名字词体验：D144 已说明不影响准入，本轮不做。

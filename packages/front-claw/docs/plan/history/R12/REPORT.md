### 客户名边界 + D138（不带括号的 2–4 字全名/昵称，记给报单人）

产品要求：放开的客户名只认 2–4 个汉字全名或昵称，后面紧跟冒号、空格或直接金额，经 `NOT_CUSTOMER_NAME` 把关；**不带括号的行也是标准格式（D102），没写员工就记给报单人**。姓+称谓（「周老师 680」）不退化。

先写测试确认当前失败（无称谓、无括号时 `parseStandardLine` 为 none，e2e 回「没太明白」），再在同一份语法 `standard-line.ts` 增加 `isOpenedSelfCustomerName` 与 `openedSelfAmountOk`：冒号/空格/紧贴的自报路径在称谓之外接受 2–4 个汉字。无称谓时金额须是阿拉伯数字或带量级/货币单位的中文，避免把「瞅一眼」「将近七百」里的「一」「七百」收成确定金额。祈使前缀（把/将/帮/请…）不当名字，以免「把许姐680那笔改成860」被当成报单。

词表覆盖一共/总共/合计/目标/本月/本周/这周/刚才/全部，以及退款、改成、大概、将近、不到、亏了、赔了、记成、重新等动词/约数/查询词。指定正例「测试员工A：680」「测试员工A 680」「测试员工A680」「小雪：1280」「小雪 1280」「阿玲 980」「李小雪：680」、带白名单备注的「小雪 1280 老客 微信」走快通道出草稿，员工=报单人（小赵）。反例「今天一共 3000」「本月目标 5万」「一共 2000」「总共 1500」「这周 800」「刚才 600」「退款 500」「改成 800」「多少 300」「大概 2000」「我 680」追问或不执行、不成标准行。「测试员工A680算我的」仍按 D137（ownership=self，出自己的草稿）；「测试员工A680报小王的」记给小王。D131：已确认「李小雪」后再发不带括号的「李小雪：880」进二选一，不直接出新草稿。尾部称谓既有写法（今天的钱姐、昨天周老师 / D124）保持。

## §1 实现要点

- 配置：`config/remark-whitelist.json`，四类：`customerType`（老客、新客、转介绍、朋友带来的）、`payment`（微信、支付宝、刷卡、现金、办卡、充值、补差价）、`praise`（不错、满意、不用找）、`project`（水光、补水、清洁、按摩、美甲、皮肤管理等常见美业项目）。
- `src/role-eval/remark-whitelist.ts` 经 `import.meta.url` 读配置；`isWhitelistedRemark` 按最长优先贪心，整条必须拼完（中间可有空白、标点、表情）；有剩余则 false。「不错」真、「老客微信」真、「不错但没做」假。

- `classifyStandardRemark`：空或纯装饰 → `allow`；整条白名单 → `allow`；出头/左右/先别记等约数 → `hedge`（解析层仍追问）；其余（含「没做」「不错但没做」）→ `model`。

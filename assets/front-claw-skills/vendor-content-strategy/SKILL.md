# 美业门店内容策略

## 安全红线

- 严禁伪造业绩入账或预约登记。严禁写库、自动外发或声称已经执行这些操作。选题表和发布计划只供员工审阅。
- 价格、档期、素材授权或数据缺失时，分别标注 `[待确认价格]`、`[待确认档期]`、`[待确认素材授权]`、`[待确认数据]`。禁用未经证实的热销数字和疗效承诺。

## 选题与交付

1. 从已确认的项目、服务范围、顾客常问问题和本地场景识别本期目标。区分了解项目、降低顾虑和发起咨询三个阶段。
2. 选取能用真实素材说明的主题，例如到店体验流程、选择项目的常见问题、护理前的准备。把同一主题改写成适合朋友圈、短视频或企微私聊的内容，保留一致的事实。
3. 给出按优先级排序的选题表。逐条写明顾客问题、切入点、渠道、所需素材、一个行动号召和观察指标。只有实际存在足够同口径数据时才做比较。
4. 汇总待确认事项和建议复盘时间。顾客素材以明确授权为前提，缺少授权时建议使用门店空镜或员工演示。

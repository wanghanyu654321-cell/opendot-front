# 美业门店文案

## 安全红线

- 严禁伪造业绩入账或预约登记。严禁写库、自动外发或宣称草稿已经发布、发送或执行。
- 缺价格、档期或数据时标注 `[待确认价格]`、`[待确认档期]`、`[待确认数据]`。未核实的评价、对比图、促销名额、医疗或绝对化功效承诺不能用于文案。

## 写作流程

1. 明确目标顾客、渠道和希望对方采取的一项行动。用顾客熟悉的词表达，一个句子说清一件事。
2. 用已知的服务环节、体验细节或适用条件支撑卖点。标题与正文保持一致。价格和活动限制只采用门店已确认信息。
3. 短视频稿按开场、体验细节、行动号召组织，附上可拍摄画面。朋友圈或团购稿说明适用范围、重要限制和下一步。私聊稿先回应问题，再给一个具体且低压力的建议。
4. 输出可人工编辑的正文，附需确认的事实和素材。未获授权的姓名、联系方式和顾客影像均不纳入草稿。

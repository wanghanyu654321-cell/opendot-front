# 客服接待与质检

## 安全红线

- 严禁伪造业绩入账或预约登记。严禁写库、自动外发或声称已预约、已退款、已通知或已转人工。
- 价格、档期、退款条款或核验资料缺失时，使用 `[待确认价格]`、`[待确认档期]`、`[待确认条款]` 或 `[待确认数据]`。勿扩散顾客姓名、联系方式或未经授权的截图。

## 接待与质检

1. 先识别顾客在咨询项目、表达价格异议、提出预约意向还是反映客诉。依据本店已核准的服务、价格和活动条款答复。
2. 对价格异议先确认顾客在意的体验或预算，再说明已核实的项目差异。客诉先承接感受，再确认事实与诉求，给出人工处理入口及待核对信息。
3. 预约意向仅记录在回复草稿中，核对项目、门店和希望时段，并说明档期由门店确认。办理记录或回执只按已核实状态描述。
4. 质检时逐项核对事实来源、过度承诺、隐私、办理状态和下一步。证据缺失则标明需复核。输出客户可读回复草稿，必要时附脱敏的人工交接建议。

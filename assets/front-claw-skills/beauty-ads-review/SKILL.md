# 本地生活团购与投流复盘

## 安全红线

- 严禁伪造业绩入账或预约登记。严禁写库、自动外发、上传客户名单、开停广告或变更预算，也不能声称已执行。
- 价格、档期、归因数据或批准预算缺失时，使用 `[待确认价格]`、`[待确认档期]`、`[待确认数据]` 或 `[待确认预算]`。未经确认的数字不能写成事实。

## 复盘步骤

1. 核对平台、门店、团购或素材、数据期间、归因窗口、金额单位与去重口径。不同窗口分别报告。
2. 对齐广告费、可归因成交与退款、有效线索和到店数据。计算线索成本须有非零的有效线索数。全店收款不能充当广告归因成交，成本不全时不推断利润。
3. 把观察与结论分开，说明问题更可能来自测量缺口、素材表现、客服承接还是样本不足。小样本仅作观察。
4. 输出最多三条建议。拟测试时写清单一变量、主指标、观察窗口、预算上限和停止条件，交由有权限的员工确认平台操作。

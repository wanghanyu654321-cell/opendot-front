# 店长经营复盘

## 安全红线

- 严禁伪造业绩入账或预约登记。严禁写库、自动外发或声称已经改账、设目标、指派任务。
- 只采用宿主提供且属于当前门店和期间的只读数据。价格、档期、目标或报数缺失时标注 `[待确认价格]`、`[待确认档期]`、`[待确认目标]` 或 `[待确认数据]`，缺失值不可折为零。

## 复盘方法

1. 核对门店、期间、来源、更新时间和单位。分开列示收款、退款、余额消耗、线索、预约及实际到店。
2. 只对照同期间、同口径的已确认目标或历史记录。分母缺失、来源冲突或退款归属不清时，指出具体缺口并保留其余可核验结论。
3. 区分异常事实、可能原因和待验证判断。对未报数列出缺少的指标、对应期间、建议核对岗位与所需凭据。
4. 给出最多三条行动建议。说明动作、建议责任岗位、核对日期及完成证据。回顾上一期行动时，以实际回执区分待处理、已处理待验证及已验证。
